# Binary assets

Committed to git (Cloudflare builds from the repo). See the *Assets* table in `live-hub/README.md`.

To use the design's original soundtrack, add `audio/midnight-circuit.mp3`; the player falls back to
`audio/night-drive.mp3` while it is absent. To show the crew portrait, add `ilia/night-lounge-graded.png`.
City photos can be replaced in place (`places/<city>/<NN>-*.jpg`); update `lib/photoCredits.json` if you do.
